1. 系统概述
================================================================================

1.1 平台简介

    易选好寓是一套面向长租公寓的在线运营管理平台，帮助公寓管理员高效管理房源
    和处理租务，同时为租客提供便捷的找房、签约、支付和报修服务。

    平台包含两个入口：
    - 管理端（Admin Web）：面向公寓管理员，端口 8081
    - 租客端（App Web）：面向租客用户，端口 8082

1.2 系统环境要求

    - 浏览器：Chrome 80+、Firefox 78+、Edge 80+ 或其他现代浏览器
    - 网络：稳定的互联网连接
    - 接口文档：启动后访问 http://localhost:<端口>/doc.html

2. 管理端使用指南
================================================================================

--------------------------------------------------------------------------------
2.1 登录与退出
--------------------------------------------------------------------------------

    访问地址：http://localhost:8081

    登录步骤：
    1. 打开管理端登录页面
    2. 页面自动加载图形验证码（60秒有效）
    3. 输入用户名、密码和图形验证码
    4. 点击"登录"按钮
    5. 登录成功后进入管理后台首页

    注意事项：
    - 图形验证码60秒过期，过期后需刷新获取新验证码
    - 登录成功后Token有效期10小时，过期需重新登录
    - 账号被禁用后无法登录，需联系超级管理员

    获取个人信息：
    - 登录后可在页面右上角查看当前登录用户信息

--------------------------------------------------------------------------------
2.2 公寓管理
--------------------------------------------------------------------------------

    功能入口：导航菜单 → 公寓管理

    【查看公寓列表】
    1. 进入公寓管理页面，系统展示所有公寓列表（分页显示）
    2. 支持按区域、发布状态等条件筛选
    3. 列表展示公寓名称、地址、联系电话、发布状态等基本信息

    【新增公寓】
    1. 点击"新增"按钮
    2. 填写公寓基本信息：
       - 公寓名称（必填）
       - 公寓简介
       - 所在地区：选择省 → 市 → 区（三级级联）
       - 详细地址
       - 经纬度（地图定位）
       - 联系电话
    3. 关联配套设施（从配套列表中选择）
    4. 关联标签（从标签列表中选择）
    5. 关联杂费（从杂费值列表中选择）
    6. 点击"保存"

    【编辑公寓】
    1. 在列表中找到目标公寓，点击"编辑"
    2. 修改公寓信息及关联数据
    3. 点击"保存"

    【查看公寓详情】
    1. 在列表中点击公寓名称或"详情"按钮
    2. 查看公寓完整信息，包括：配套设施列表、标签列表、图片列表、杂费列表

    【发布/取消发布公寓】
    1. 在列表中找到目标公寓
    2. 点击"发布"或"取消发布"按钮
    3. 发布后公寓对租客可见，取消发布后租客无法看到

    【删除公寓】
    1. 在列表中点击"删除"按钮
    2. 系统校验该公寓下是否存在房间
    3. 若存在关联房间则删除失败，需先删除所有房间
    4. 确认后执行删除（逻辑删除）

--------------------------------------------------------------------------------
2.3 房间管理
--------------------------------------------------------------------------------

    功能入口：导航菜单 → 房间管理

    【查看房间列表】
    1. 进入房间管理页面，展示所有房间列表（分页）
    2. 支持按公寓、发布状态筛选
    3. 支持根据公寓ID查看该公寓下所有房间

    【新增房间】
    1. 点击"新增"按钮
    2. 填写房间信息：
       - 所属公寓（下拉选择）
       - 房间号（必填）
       - 月租金（必填，单位：元）
    3. 关联属性值（如朝向、面积、楼层等）
    4. 关联配套设施
    5. 关联标签
    6. 上传房间图片
    7. 选择可选租期
    8. 选择可选支付方式
    9. 点击"保存"

    【编辑房间】
    1. 找到目标房间，点击"编辑"
    2. 修改房间信息及所有关联数据
    3. 点击"保存"

    【发布/取消发布房间】
    - 操作方式与公寓相同
    - 发布后房间对租客可见

    【删除房间】
    - 系统校验是否存在有效租约
    - 若存在租约则删除失败，需先处理租约

--------------------------------------------------------------------------------
2.4 基础配置管理
--------------------------------------------------------------------------------

    2.4.1 属性管理
    ──────────────
    - 属性名称：如"朝向"、"面积"、"楼层"等
    - 属性值：如朝向下的"南"、"北"、"东"、"西"
    - 操作：新增/编辑/删除属性名称和属性值
    - 注意：删除属性名称会自动删除其下所有属性值

    2.4.2 配套管理
    ──────────────
    - 配套分为"公寓配套"和"房间配套"两种类型
    - 每个配套包含名称和图标
    - 操作：新增/编辑/删除，可按类型筛选查看

    2.4.3 杂费管理
    ──────────────
    - 杂费名称：如"水费"、"电费"、"物业费"等
    - 杂费值：如水费下的"5元/吨"
    - 操作：新增/编辑/删除杂费名称和杂费值
    - 注意：删除杂费名称会自动删除其下所有杂费值

    2.4.4 标签管理
    ──────────────
    - 标签分为"公寓标签"和"房间标签"两种类型
    - 如"近地铁"、"精装修"、"拎包入住"等
    - 操作：新增/编辑/删除，可按类型筛选

    2.4.5 租期管理
    ──────────────
    - 配置可选租期，以月数为单位
    - 如3个月、6个月、12个月等
    - 操作：新增/编辑/删除

    2.4.6 支付方式管理
    ──────────────
    - 配置租金支付方式
    - 如"押一付一"（付1个月）、"押一付三"（付3个月）等
    - 每种支付方式包含付月数和补充说明
    - 操作：新增/编辑/删除

--------------------------------------------------------------------------------
2.5 租约管理
--------------------------------------------------------------------------------

    功能入口：导航菜单 → 租约管理

    【创建租约】
    1. 点击"新增"按钮
    2. 填写租约信息：
       - 租客姓名、手机号、身份证号
       - 选择公寓和房间
       - 选择租期
       - 填写月租金和押金
       - 选择支付方式
       - 设置租赁起止日期
    3. 点击"保存"
    4. 租约初始状态为"签约待确认"

    【查看租约列表】
    - 分页展示所有租约
    - 支持按公寓、房间、状态等条件筛选
    - 查看租约详情

    【租约状态操作】
    - 确认签约：将"签约待确认" → "已签约"
    - 确认退租：将"退租待确认" → "已退租"
    - 确认续约：将"续约待确认" → "已签约"（生成新租约）

    【删除租约】
    - 确认后执行逻辑删除

    租约状态说明：
    ┌─────────────┬──────────────────────────────────────────┐
    │ 状态        │ 含义                                     │
    ├─────────────┼──────────────────────────────────────────┤
    │ 签约待确认  │ 管理员已创建租约，等待租客确认            │
    │ 已签约      │ 租客已确认，租约生效                      │
    │ 已取消      │ 租约被取消                                │
    │ 已到期      │ 租期结束                                  │
    │ 退租待确认  │ 租客申请退租，等待管理员确认              │
    │ 已退租      │ 管理员确认退租，租约终止                  │
    │ 续约待确认  │ 租客申请续约，等待管理员确认              │
    └─────────────┴──────────────────────────────────────────┘

2.6 预约看房管理
--------------------------------------------------------------------------------

    功能入口：导航菜单 → 预约看房

    【查看预约列表】
    - 分页展示所有看房预约
    - 显示预约人姓名、电话、预约公寓、预约时间、预约状态

    【更新预约状态】
    - 待看房：租客已提交预约，等待看房
    - 已看房：看房已完成
    - 已取消：预约被取消

--------------------------------------------------------------------------------
2.7 报修管理
--------------------------------------------------------------------------------

    功能入口：导航菜单 → 报修管理

    【查看报修列表】
    - 分页展示所有报修工单
    - 显示报修标题、房间、优先级、状态、提交时间

    【查看报修详情】
    1. 点击报修工单查看详情
    2. 详情包含：报修描述、附件图片、报修进度记录

    【指派处理人】
    1. 选择待处理的报修工单
    2. 指派处理人
    3. 报修状态从"待处理"变为"处理中"

    【添加进度记录】
    1. 在处理中的报修工单中添加进度
    2. 填写进度描述内容
    3. 系统自动记录操作人和操作时间

    【更新报修状态】
    - 处理中 → 已完成：处理完成后更新
    - 待处理 → 已取消：特殊情况下管理员可取消

    报修优先级说明：
    - 低：不影响正常居住的小问题
    - 中：影响使用但不紧急
    - 高：严重影响居住，需优先处理

2.11 租户画像

    【查看租户画像列表】

3. 租客端使用指南
================================================================================

--------------------------------------------------------------------------------
3.1 注册与登录
--------------------------------------------------------------------------------

    访问地址：http://localhost:8082

    登录步骤：
    1. 打开租客端页面
    2. 输入手机号
    3. 点击"获取验证码"按钮
    4. 等待收到短信验证码（10分钟内有效）
    5. 输入验证码
    6. 点击"登录"按钮
    7. 登录成功

    注意事项：
    - 首次登录的手机号会自动注册账号
    - 验证码10分钟内有效，过期需重新获取
    - 登录Token有效期10小时

    获取个人信息：
    - 登录后可查看当前登录用户信息

--------------------------------------------------------------------------------
3.2 浏览房源
--------------------------------------------------------------------------------

    【浏览公寓】
    1. 查看公寓详情页面
    2. 公寓信息包含：名称、简介、地址、联系电话
    3. 查看公寓配套设施、标签、图片、杂费标准

    【浏览房间】
    1. 进入房源列表页面
    2. 支持按以下条件筛选：
       - 区域（省/市/区）
       - 租金范围
       - 租期
    3. 点击房间查看详情：
       - 房间号、月租金
       - 房间属性（朝向、面积等）
       - 配套设施
       - 标签
       - 图片
       - 可选租期
       - 可选支付方式

    【浏览提示】
    - 浏览房间会自动记录到浏览历史
    - 可以对感兴趣的房间进行收藏

--------------------------------------------------------------------------------
3.3 预约看房
--------------------------------------------------------------------------------

    【创建预约】
    1. 在公寓详情页或预约入口点击"预约看房"
    2. 填写预约信息：
       - 姓名
       - 联系电话
       - 预约看房时间
       - 补充信息（可选）
    3. 提交预约
    4. 预约状态为"待看房"

    【查看预约】
    - 在个人中心查看预约列表
    - 查看预约详情
    - 可更新预约信息

    预约状态：
    - 待看房：预约已提交，等待看房
    - 已看房：看房已完成
    - 已取消：预约已取消

--------------------------------------------------------------------------------
3.4 签约与租约管理
--------------------------------------------------------------------------------

    【查看租约列表】
    1. 进入"我的租约"页面
    2. 查看所有个人租约

    【确认租约】
    1. 管理员创建租约后，租客端会收到通知
    2. 查看租约详情：公寓、房间、租期、租金、押金、支付方式
    3. 确认无误后点击"确认签约"
    4. 租约状态从"签约待确认"变为"已签约"

    【申请退租】
    1. 在已签约的租约中点击"申请退租"
    2. 租约状态变为"退租待确认"
    3. 等待管理员确认退租
    4. 管理员确认后租约状态变为"已退租"

    【续约】
    1. 在租约中点击"续约"
    2. 填写续约信息
    3. 生成新的租约，状态为"续约待确认"
    4. 等待管理员确认

    租约状态流程：
    签约待确认 → 已签约 → 退租待确认 → 已退租
    已签约 → 续约待确认 → 已签约（新租约）

--------------------------------------------------------------------------------
3.5 账单与支付
--------------------------------------------------------------------------------

    【查看账单】
    1. 在租约详情中查看账单列表
    2. 账单类型分为：
       - 押金：签约时一次性支付
       - 租金：按周期支付
    3. 账单状态：待支付、已支付、已逾期、已取消

    【查看当前应付账单】
    - 快速查看当前需要支付的账单

    【支付流程】
    1. 选择待支付的账单
    2. 进入支付预览页面，查看：
       - 应付金额明细（押金 + 租金）
       - 可选支付方式
    3. 选择支付方式：
       - 纯支付宝支付
       - 纯微信支付
       - 混合支付（余额 + 微信）
    4. 确认支付
    5. 系统创建支付订单
    6. 完成支付后账单状态更新为"已支付"

    【查看支付历史】
    - 在个人中心查看已支付的账单汇总

    【退款】
    1. 退租后可申请退款
    2. 退款按原支付渠道原路退回
    3. 查看退款进度和状态

--------------------------------------------------------------------------------
3.6 报修服务
--------------------------------------------------------------------------------

    【提交报修】
    1. 进入"报修"功能
    2. 选择报修房间（从名下房间中选择）
    3. 填写报修信息：
       - 报修标题（简要描述问题）
       - 详细描述
       - 优先级（低/中/高）
       - 预约维修时间
       - 联系电话
    4. 上传附件图片（可选，如问题照片）
    5. 提交报修

    【查看报修】
    - 查看个人报修列表
    - 查看报修详情和进度

    【撤销报修】
    - 仅"待处理"状态的报修可以撤销
    - 点击"撤销"按钮即可

    报修流程：
    提交报修（待处理）→ 管理员指派处理人（处理中）→ 处理完成（已完成）

--------------------------------------------------------------------------------
3.7 房间收藏
--------------------------------------------------------------------------------

    【收藏房间】
    1. 在房间详情页点击收藏图标
    2. 收藏状态切换（已收藏/已取消）

    【查看收藏】

4. 常见问题与解决方案
================================================================================

Q1：验证码收不到怎么办？
A1：请检查以下内容：
    - 手机号是否正确
    - 手机信号是否正常
    - 短信是否被拦截（检查垃圾短信箱）
    - 等待1-2分钟后重新获取
    - 若持续收不到，联系管理员检查短信服务配置

Q2：登录后提示"Token过期"怎么办？
A2：Token有效期为10小时，过期后需重新登录获取新Token。

Q3：图形验证码看不清怎么办？
A3：点击验证码图片可刷新获取新的验证码。

Q4：公寓/房间删除失败？
A4：系统会自动检查关联数据：
    - 公寓下有房间时不能删除，需先删除所有房间
    - 房间有有效租约时不能删除，需先处理租约

Q5：支付后账单状态未更新？
A5：支付回调可能有短暂延迟，请稍后刷新页面查看。若长时间未更新，
    请联系管理员手动确认支付状态。

Q6：如何修改租金支付方式？
A6：支付方式在租约创建时确定，如需修改请联系管理员重新创建租约。

Q7：报修提交后可以修改吗？
A7：报修提交后不支持直接修改，但可以撤销后重新提交（仅"待处理"状态可撤销）。

Q8：退租后押金如何退还？
A8：退租确认后可申请退款，押金将按原支付渠道原路退回。退款处理时间
    视支付渠道而定，一般1-3个工作日。

Q9：AI助手无法回答问题？
A9：AI助手主要处理房源相关查询，超出能力范围的问题可能无法回答。
    如遇AI服务不可用，请检查DeepSeek API配置和调用额度。

Q10：接口文档在哪里查看？
A10：启动服务后访问以下地址：
     - 管理端：http://localhost:8081/doc.html
     - 租客端：http://localhost:8082/doc.html
