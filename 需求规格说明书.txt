《易选好寓》需求规格说明书
版本：V1.0
日期：2025-11-03

1. 引言
1.1 背景
    易选好寓是一个基于 Spring Boot + Vue 的前后端分离租赁管理平台，提供租客端（App Web）与管理端（Admin Web）两套应用，支持房源展示、租赁流程管理、支付及后台运营等功能。
1.2 目标
    明确系统范围、用户角色、功能及非功能需求，为后续的设计、开发、测试与运维提供统一依据。
1.3 读者对象
    产品经理、架构师、后端/前端开发、测试人员、运维工程师以及项目干系人。
1.4 参考资料
    - 项目源代码（common、model、web 模块）
    - 数据库设计文档（若有）
    - 行业租赁业务流程规范

2. 项目概述
2.1 系统定位
    面向公寓租赁业务的 SaaS 解决方案，提供租客在线找房、预约、签约及支付体验，并为运营管理提供房源、租期、费用、合同及客服支撑。
2.2 用户角色
    - 租客用户：通过 App Web 端浏览与管理个人租赁业务。
    - 管理员用户：通过 Admin Web 端维护房源、租期、合同及运营数据。
    - 系统接口：与阿里云短信、MinIO 对象存储、OpenAI/DeepSeek 模型服务、Redis 缓存等外部系统交互。
2.3 系统边界
    本系统提供 RESTful API，通过前端（Vue）页面或移动客户端调用；数据库使用 MySQL，缓存与会话管理依赖 Redis；文件资源通过 MinIO 存储。

3. 功能性需求
3.1 租客端（web-app 模块）
    3.1.1 登录与认证
        - 支持手机号+短信验证码登录，验证码由阿里云短信服务发送并存储于 Redis，过期时间 10 分钟。
        - 登录成功后颁发 JWT，前端在请求头中携带。
    3.1.2 用户信息管理
        - 获取当前登录用户基础资料（昵称、头像）。
        - 首次登录自动创建用户信息，默认头像存储于 MinIO。
    3.1.3 房源查询
        - 根据城市/区域/公寓筛选房源列表。
        - 查看单个房源详情（户型、租金、配套、费用、标签等）。
        - 支持房源收藏、浏览历史记录。
    3.1.4 预约与合同
        - 发起看房预约，记录预约时间、联系人信息。
        - 查看历史预约记录与状态。
        - 查看/下载租赁合同及租期信息。
    3.1.5 租赁操作
        - 在线发起租赁申请，选择租期与支付方式。
        - 生成租约并同步状态至后台。
    3.1.6 支付与账单
        - 查看账单列表、支付计划与费用明细。
        - 支持线下/第三方支付方式维护（由后台配置）。
    3.1.7 AI 咨询（可选）
        - 通过 Spring AI 集成 DeepSeek 模型，提供租房咨询或客服问答接口。
    3.1.8 通知与消息
        - 提供短信验证码通知，预留站内消息接口（后续扩展）。

3.2 管理端（web-admin 模块）
    3.2.1 登录与安全
        - 管理员账号密码登录，支持图形验证码（Redis 存储，有效期 60 秒）。
        - 登录后获取后台管理权限，支持账号状态禁用。
    3.2.2 房源与公寓管理
        - 维护公寓基础信息、楼栋单元、房间详情。
        - 配置房间属性（面积、朝向、楼层、状态）和配套设施。
        - 批量管理租期（Lease Term）、租金与费用模板。
    3.2.3 地区与标签
        - 管理城市/区域/地理层级数据，以支持前端筛选。
        - 维护房源标签、特色标签等元数据。
    3.2.4 文件与媒体
        - 通过 MinIO 上传房源图片、合同附件，并记录文件 URL。
    3.2.5 租约与订单
        - 审核租客发起的租约，维护合同状态（待签、进行中、已完成、已退租）。
        - 管理账单与支付记录，支持费用调整。
    3.2.6 用户管理
        - 查看租客用户列表，支持账号禁用、信息维护。
    3.2.7 定时与运营任务
        - 启用定时任务（EnableScheduling）执行账单生成、租期检查等运营任务。
    3.2.8 报表与统计（预留）
        - 预留接口用于房源入住率、收入统计等数据分析。

3.3 公共服务（common 模块）
    - 统一异常处理与返回结构（Result、ResultCodeEnum、LeaseException）。
    - Redis 常量与工具类，封装验证码/缓存键名。
    - 登录上下文（LoginUserHolder）读取 JWT 中的用户信息。
    - 短信服务封装（集成阿里云 SMS）。
    - MinIO 客户端封装，用于文件上传。
    - 验证码工具（图片验证码、数字验证码）。

4. 非功能性需求
4.1 性能
    - 主要业务接口平均响应时间 ≤ 500ms，峰值 TPS ≥ 200（缓存命中场景）。
    - 使用 Redis 缓存热点数据，减少数据库压力。
4.2 可用性
    - 系统可用性 ≥ 99.5%，关键服务需提供健康检查。
4.3 扩展性
    - 采用模块化设计，支持新增业务模块（如客服、营销活动）。
    - 支持横向扩容（无状态服务配合负载均衡）。
4.4 安全性
    - 使用 HTTPS 保护传输安全。
    - JWT Token 需设置合理过期时间，支持刷新机制（后续扩展）。
    - 重要配置（数据库、Redis、OpenAI、短信密钥）需通过环境变量或配置中心管理，不直接暴露在仓库。
4.5 可维护性
    - 代码采用统一风格与注释规范，核心业务配合单元测试。
    - 通过 Knife4j/OpenAPI 提供接口文档。
4.6 兼容性
    - 后端要求 JDK 17，数据库 MySQL 8.x，Redis 6.x，MinIO 兼容 S3 API。

5. 外部接口需求
5.1 数据库
    - MySQL：存储用户、房源、公寓、租约、账单等业务数据。
5.2 缓存
    - Redis：用于验证码、会话、热点数据缓存。
5.3 对象存储
    - MinIO：存储房源图片、合同文件、头像等非结构化数据。
5.4 短信服务
    - 阿里云短信：提供验证码发送能力，需要配置 AccessKey、Secret。
5.5 AI 服务
    - DeepSeek（OpenAI 协议）：提供自然语言问答服务，配置 API Key 与 Base URL。

6. 数据需求
    - 数据模型由 model 模块定义，包含 SystemUser、UserInfo、Apartment、Room、LeaseAgreement、LeaseTerm 等实体。
    - 需确保实体字段与数据库表结构一致，使用 MyBatis-Plus 完成 ORM 映射。
    - 重要字段（手机号、身份证、合同号）需设置唯一约束。

7. 安全与权限控制
    - 租客端与管理端通过独立 JWT 鉴权；后台可进一步细化角色与权限（后续扩展为 RBAC）。
    - 登录验证码、短信验证码需防重放与限制频次（当前 Redis 控制 60 秒重发间隔）。
    - 上传文件需做类型与大小校验，防止恶意脚本。

8. 运维与部署需求
    - 后端服务提供 Dockerfile 或部署脚本（后续补充）。
    - 运行依赖：JDK 17、Maven、MySQL、Redis、MinIO。
    - 根据环境拆分配置文件（dev/test/prod），敏感信息通过环境变量注入。
    - 监控：集成 Spring Boot Actuator 或自定义健康检查。

9. 约束与依赖
    - 后端框架：Spring Boot 3.3.8。
    - 持久层框架：MyBatis-Plus 3.5.6。
    - 缓存：Spring Data Redis。
    - 对象存储：MinIO Java SDK 8.2.0。
    - 短信：阿里云 dysmsapi20170525。
    - AI：Spring AI 1.0.0-M5。
    - 前端技术栈：Vue（具体项目单独维护）。

10. 验收标准
    - 所有必需功能按用例通过测试，包括登录、房源查询、预约、签约、后台管理等。
    - 接口通过集成测试和手动验收，Swagger/Knife4j 文档准确。
    - 非功能指标经压测或演练验证。
    - 部署文档完整，可在测试环境完成一键部署。
